Entry for the make.fun **Sum up 25 November's world news in one image** (`news-image-20261125`) competition.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Reads the bundled 1024×1024 `entry.png`, verifies its size limit (`<= 1,048,576` bytes) and SHA-256 digest, and writes the exact image bytes to `${MAKEFUN_OUTPUT_DIR:-/output}/entry.png`.
